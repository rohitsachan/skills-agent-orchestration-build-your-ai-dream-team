# Mona's Project Pulse Agent Team

I will use a four-agent custom team to build Mona's Project Pulse dashboard:

- Orchestrator: coordinates the work, breaks the dashboard build into phases, delegates tasks to specialists, and keeps the overall effort aligned with the project goals.
- Planner: researches the repo and requirements, identifies dependencies and edge cases, and produces the implementation strategy and file ownership plan before coding begins.
- Designer: focuses on the dashboard experience, including layout, accessibility, information hierarchy, responsive behavior, and polished visual treatment for the Project Pulse UI.
- Coder: implements the actual code, fixes issues, and handles app support tasks such as launch configuration for the dashboard so it can be previewed and validated.

This team gives me a clear workflow: plan first, design the dashboard experience, then implement the code in scoped phases under the Orchestrator's coordination.
